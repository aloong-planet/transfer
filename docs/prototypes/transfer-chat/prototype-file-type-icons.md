# File type icons

## Question

Which icon each of eight file categories gets when files are sent and received: image, video, audio, PDF, archive, document, spreadsheet and the fallback for everything else. And what to do about PDF, since Lucide has no dedicated PDF glyph.

## Structure basis

The geometry is the app's: a 30×30 rounded block holding a 17px icon, on the accent-soft background (files from the other party and the received-files list) or the own-wash background (files sent from this device).

## Demo scaffolding

Not part of the design; do not implement. The selection tables: the current emoji row, candidate sets A and B, the PDF candidates, and the realistic-context row.
