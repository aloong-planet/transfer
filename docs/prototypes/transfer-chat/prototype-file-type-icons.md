# File type icons

## Question

Which icon each of eight file categories shows when files are sent and received: image, video, audio, PDF, archive, document, spreadsheet and the fallback for everything else. The page shows the eight icons in a table, then in the received-files list and in a file bubble the user sent. PDF and document share one glyph.

## Structure basis

The geometry is the app's: a 30×30 rounded block holding a 17px icon, on the accent-soft background (files from the other party and the received-files list) or the own-wash background (files sent from this device).
