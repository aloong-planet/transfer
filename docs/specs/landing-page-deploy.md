# 落地页的部署形态(一份代码两处部署)

> 关联: ADR-0011(移除 Gitee 镜像) · ADR-0018(落地页进大陆节点,下载源不动)
> 运维步骤见 `docs/ops/`,本文只写需求全景与边界。

## Problem Statement

落地页目前只部署在 Cloudflare Pages(`transfer.aloongplanet.com`)。ADR-0011 已实测坐实:**不备案的 Cloudflare 不接大陆节点**,大陆用户打开落地页要绕境外,首屏慢。

现在 `aloongplanet.com.cn` 已完成 ICP 备案、自有 ECS 已配好反向代理与证书,具备了让大陆用户从境内节点打开落地页的条件。

## Solution

**同一份落地页代码构建两次,部署到两个域名。** 两份产物只有一处差异:国内那份的页脚多一条 ICP 备案号(法规要求)。下载源、文案、结构、样式全部相同。落地页的代码与规则在 aloong-planet-home([transfer-site](https://github.com/aloong-planet/aloong-planet-home/blob/main/docs/specs/transfer-site.md)),本仓库不含站点代码;国内那份由本仓库的部署命令取该仓库当前的 main 构建。

大陆用户因此拿到快的**页面**;**下载仍走境外**——安装包在未备案的 R2 上,这一半没有改变(见 ADR-0018 的「Consequences」)。

## User Stories

1. As a 大陆访客, I want 落地页从境内节点快速打开, so that 我不会因为白屏先离开。
2. As a 大陆访客, I want 在页脚看到备案号并能点击核验, so that 我确认这是合规站点。
3. As a 站主, I want 两处部署共用同一份代码, so that 改一次文案两边都更新,不会随时间分叉成两个站。
4. As a 站主, I want `.com` 那份**不出现**中国备案号, so that 它对境外访客既不突兀也不误导。
5. As a 站主, I want 国内站上线完全不影响已在跑的 Pages 部署, so that 不必为了新增一个部署去动旧的。
6. As a 站主, I want 一条命令完成国内站的构建与同步, so that 站点改动后上线国内站时不用回忆步骤。
7. As a 大陆访客, I want 下载按钮照常可用(哪怕慢), so that 镜像站不是个只能看不能下的残废站。

## 失败模式与边界

### 备案号的渲染

| 情形 | 预期行为 |
|---|---|
| 环境变量未设置(`.com` 构建) | 该项**整个不渲染**——不是渲染成空、也不是留一段空白间距。**页脚高度与只有品牌和链接两项时一致** |
| 环境变量已设置且合法(国内构建) | 在页脚同一行的品牌与链接之间出现,链接指向工信部核验页,**页脚高度与未设置时相同** |
| 环境变量设置了但**格式非法** | **构建失败** |
| 备案号**合法的形态** | 整个值是 `<省份简称>ICP备<数字>号`,后面可以再带一个 `-<序号>` 后缀(同主体多站点时用):省份简称是 1 至 2 个汉字,`ICP备` 之后是 4 位及以上的数字,序号是一个或多个数字。不符合这一形态的即「格式非法」。这一形态来自常识,没有逐个核对过真实备案号 |
| 环境变量**存在但为空串或纯空白** | 视同未设置,不渲染、不报错 |
| 环境变量的值是合法备案号、前后带空白 | 视同合法:接受,渲染时去掉前后的空白 |
| 英文页 `/en/` | **同样渲染** |
| **首页以外的页面**(隐私政策页及其英文版) | **同样渲染** |
| 窄屏 | 页脚三项换行自然堆叠(品牌与备案号同行、链接落到下一行)。备案号**不得被截断、不得溢出容器**,页面不得出现横向滚动 |
| 深色主题 | 分隔线与文字颜色随主题切换,不是固定色值 |

### 下载与统计(与既有功能的回归点)

| 情形 | 预期行为 |
|---|---|
| 在国内站点下载 | 走与 `.com` **完全相同**的下载区([transfer-site::REQ-002](https://github.com/aloong-planet/aloong-planet-home/blob/main/docs/specs/transfer-site.md)) |
| 国内站的 origin 不在 R2 的 CORS 白名单里 | 最新版指针与统计请求都被拒 → **静默隐藏统计行**,下载区落到 [transfer-site::REQ-002/AC-02](https://github.com/aloong-planet/aloong-planet-home/blob/main/docs/specs/transfer-site.md) 或 [transfer-site::REQ-002/AC-03](https://github.com/aloong-planet/aloong-planet-home/blob/main/docs/specs/transfer-site.md) 的状态,页面其余部分完全正常 |
| 白名单补上之后 | 统计行正常出现,下载区回到 [transfer-site::REQ-002/AC-01](https://github.com/aloong-planet/aloong-planet-home/blob/main/docs/specs/transfer-site.md),无需改代码或重新部署 |
| R2 下载慢或超时 | 浏览器自身行为,不干预(见 Out of Scope) |

### 构建与部署

| 情形 | 预期行为 |
|---|---|
| `.com` 构建不设备案号变量 | 构建成功 |
| aloong-planet-home 的 CI 构建站点时不设环境变量 | 构建成功 |
| **部署国内站时忘了设备案号变量** | 不允许发生。部署命令**自己保证**备案号被注入。真忘了(比如手工绕过该命令)时,构建出的产物应当在部署自检中被发现 |
| 部署脚本收到的不是构建产物目录 | **报错退出**,不能把错误内容推上服务器 |
| 同步后文件权限 | 必须在服务器侧显式修正,让反代容器里的 nginx 用户读得到新文件 |
| 同步时旧文件被删除 | 上一版有而新产物里没有的文件从服务器上删除,不留孤儿文件 |

### 引入内容带来的能力

备案号的唯一外部输入是**构建期环境变量**,它的值会进入 HTML。

| 交互面 | 行为归宿 |
|---|---|
| 备案号文本插入 HTML | 转义后作为文本插入,不原样注入 HTML |
| 备案号链接的目标 | **固定**(目标见「环境变量已设置且合法」一行),不由环境变量决定 |
| 链接的打开方式 | 新标签打开,带 `rel="noopener"` |

## Implementation Decisions

- **备案号通过构建期环境变量注入**。国内构建设置它,Cloudflare Pages 不设。这样两边代码一字不差,Pages 控制台也不用改。
- **可选,但一旦设置就必须合法**。未设 → 不渲染;设了但格式不对 → 构建失败。这与个人主页那边"必填否则构建失败"的语义**相反**,照抄会让 `.com` 的构建挂掉。
- **备案号不进 i18n 字典**。它是法规信息,不翻译;且是专有值,不是文案。
- **页脚布局(来自已确认的原型)**:**不另起一行**。备案号作为页脚那一行的第三项,落在品牌与链接之间,由既有的两端对齐自动把它推到中间。字号小于产品链接、用弱化前景色——它是页面的法律附注,层级低于产品链接。`.com` 构建下该项**整个不存在**,页脚退回「品牌 | 链接」两端对齐,与改动前逐像素一致(实测两种状态页脚高度同为 26px)。
- **部署走手动脚本**,一条命令完成构建 + 同步 + 服务器侧权限修正 + 自检。选它而不是 CI 自动部署的理由见 ADR-0018。
- **不引入 canonical / sitemap**。`astro.config` 的 `site` 字段当前没有任何消费者,本轮不给它造消费者;两个域名的重复内容问题一并留到真需要 SEO 时再议。

## Out of Scope

- **下载源搬迁到境内**。这是 ADR-0011 选项 3 的另一半,本轮明确不做;大陆下载速度不因本轮改变。
- **自动化部署**。放行 GitHub Actions 出口 IP 物理上不可行(7297 个网段);self-hosted runner 有把同机 Harbor 挤 OOM 的风险;OSS 中转多一个活动部件。落地页三周只改过 10 次,不值得。将来要做,OSS 中转是最干净的那条。
- **canonical / sitemap / 两域名重复内容的 SEO 处理**。
- **在 Cloudflare 控制台点开 R2 的 CORS 白名单**这一步本身。但仓库里的策略文件是那份配置的真源,**必须同步加上国内站的 origin**——只改控制台会让两边分叉,下次照文件重贴就把国内站的统计打回原形。验证命令要覆盖两个 origin 并带阴性对照:只验白名单内的 origin 分不清「白名单生效」与「桶对所有人开放」。
- **国内站的下载提速或提示文案**。先上线看真实反馈,不为想象中的慢提前做优化。
- **公安联网备案号**。尚未申请;号下来后与个人主页同样处理。

## Further Notes

- 目标机器与个人主页同一台 ECS,上面还跑着 Harbor / Nginx Proxy Manager / Portainer。**本轮任何改动都不得影响那些既有服务**:不抢宿主端口、不改 Docker 守护进程配置、不重启反代以外的容器。可用内存约 860MB,很紧。
- 开发机常驻 TUN 模式代理,会劫持系统解析器并对任意目标返回连接成功。**在本机做的网络连通性测试一律不作数**;验证从服务端(日志、抓包)或独立网络进行。
